# Acorn File Forge 1.2.1

Acorn File Forge 1.2.1 updates the Oaknut filesystem engine from 12.17.1 to
12.18.2. It changes no editing, repair or format behaviour.

This is the first release that 1.2.0 can install itself: open **About Acorn
File Forge** from the **Help** menu, press **Check for Application Updates**,
then **Update to 1.2.1**.

## Changes

- Oaknut Disc, ADFS and ROMFS move from 12.17.1 to 12.18.2. Upstream, DFS now
  takes the disc size from the catalogue rather than the image length and
  accepts images trimmed part-way through a sector after the last file, so
  more real-world SSD and DSD images open. ADFS lists the Arculator and
  BlueSCSI `.hdf` and `.hda` hard-disc suffixes, which were already opened by
  content. The Debian package lock carries all thirteen Oaknut packages at
  12.18.2, so the native package is assembled from one Oaknut release.
- Oaknut 12.18 reads a BeebSCSI or Pi1MHz `.cfg` geometry sidecar and prefers
  it to a `.dsc`. Acorn File Forge still pairs a BeebSCSI DAT only with its
  DSC, so the geometry it edits against is unchanged. The
  [Oaknut FileCore notes](../OAKNUT-FILECORE-SUPPORT.md) describe this.
- The third-party notices link Oaknut's real repository,
  `rob-smallshire/oaknut`, in place of an address that did not exist. A
  documentation test now checks the link against the repository Oaknut
  declares in its own package metadata.
- Install commands name each package as GitHub publishes it, with the tilde
  of the Debian revision as a dot, for example
  `acorn-file-forge_1.2.1-1.deb13_amd64.deb`.

## Repair and format behaviour

No format restriction or repair behaviour changes in this release. Images and
packages written by 1.2.0 and 1.2.1 are interchangeable. The bundled
HxCFloppyEmulator runtime is unchanged.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./acorn-file-forge_1.2.1-1.deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime for HFE and SCP media.

Installing 1.2.1 over 1.2.0 preserves native XDG workspace data and Docker
working volumes. Save important open images before upgrading.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
