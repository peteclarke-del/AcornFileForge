# Acorn File Forge 1.1.3

Acorn File Forge 1.1.3 updates the Oaknut filesystem engine from 12.16.0 to
12.17.1. It changes no editing, repair or format behaviour.

## Changes

- Oaknut Disc, ADFS and ROMFS move from 12.16.0 to 12.17.1. Upstream, the
  release changes how Oaknut's own `put` and bulk-import commands derive an
  in-image name from a host file and its INF sidecar, keeps the INF load and
  execution words when the attribute field is symbolic, and makes the
  oaknut-basic console script self-sufficient. Acorn File Forge performs its
  own imports and INF handling, so its behaviour is unchanged; the full suite
  and the six browser regressions pass against the new engine. The Debian
  package lock carries all thirteen Oaknut packages at 12.17.1 so the native
  package is assembled from one Oaknut release.
- The three Oaknut bumps were applied together, as the consistency checks
  added in 1.1.2 require, and the requirements-parser example in the test
  suite no longer quotes a real release number.

## Repair and format behaviour

No format restriction or repair behaviour changes in this release. Images and
packages written by 1.1.2 and 1.1.3 are interchangeable. The bundled
HxCFloppyEmulator runtime is unchanged.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./acorn-file-forge_1.1.3-1.deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime for HFE and SCP media.

Installing 1.1.3 over 1.1.2 preserves native XDG workspace data and Docker
working volumes. Save important open images before upgrading.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
