# Acorn File Forge 1.1.2

Acorn File Forge 1.1.2 updates the filesystem engine, the application server,
the browser test harness and the release workflow's GitHub Actions to their
current releases. It changes no editing, repair or format behaviour.

## Changes

- Oaknut Disc, ADFS and ROMFS move from 12.15.1 to 12.16.0. The release adds
  an opt-in greedy crunch mode to the BBC BASIC tokeniser, which Acorn File
  Forge does not select, so tokenised BASIC saved by this release is
  byte-identical to that saved by 1.1.1. The Debian package lock carries all
  thirteen Oaknut packages at 12.16.0 so the native package is assembled from
  one Oaknut release.
- Gunicorn moves from 26.1.0 to 26.2.0. The release fixes header handling on
  its HTTP/2 path and adds cleartext HTTP/2. Acorn File Forge serves HTTP/1.1
  on port 8666 and does not enable either mechanism.
- Playwright, used only by the browser regression suite, moves from 1.62.1 to
  1.63.0.
- The release workflow uses actions/cache 6 and actions/download-artifact 8.
  The download action now fails the run on an artifact digest mismatch rather
  than warning, so a corrupted package cannot reach the published release.
- Added checks that fail the suite when a dependency bump leaves the Debian
  package lock, the third-party notices, the handbooks or the in-app help
  naming a superseded Oaknut release. Each of the four bumped dependency pull
  requests had failed continuous integration on exactly that drift.

## Repair and format behaviour

No format restriction or repair behaviour changes in this release. Images and
packages written by 1.1.1 and 1.1.2 are interchangeable. The bundled
HxCFloppyEmulator runtime is unchanged.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./acorn-file-forge_1.1.2-1~deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime for HFE and SCP media.

Installing 1.1.2 over 1.1.1 preserves native XDG workspace data and Docker
working volumes. Save important open images before upgrading.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
