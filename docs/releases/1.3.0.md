# Acorn File Forge 1.3.0

Acorn File Forge 1.3.0 adds floppy drive panes for Greaseweazle on the Linux
desktop, and conversion of floppy images between DFS and ADFS in every
edition. It also moves the Oaknut filesystem engine from 12.18.2 to 13.6.1.

1.2.0 and later can install this release from **Help → About Acorn File
Forge → Check for Application Updates**.

## New: floppy drive panes (Linux desktop)

Choose **Open floppy drive** in an empty pane, or **File → Open floppy
drive…**, to read the disk in a Greaseweazle drive into an ordinary pane.

- The disk's format is identified from a short read of four tracks. Detection
  covers DFS 40 or 80 track, single or double sided; ADFS S, M and L; ADFS
  D/E; and ADFS F. A 40-track disk in an 80-track drive is read with double
  stepping.
- A blank disk offers formatting, which needs a ticked confirmation. A disk
  that cannot be identified asks for the format instead.
- Edits stay in the pane. Its header shows whether the disk still matches,
  and **Write to disk** writes every track and verifies it. Nothing is written
  until you choose it. Closing a pane with unwritten changes asks first.
- Sectors that cannot be read are reported by count and filled with zeros.

See the [physical floppy guide](../PHYSICAL-FLOPPY-GUIDE.md).

## New: convert between DFS and ADFS

**Tools → Convert to ADFS…** on a DFS pane, or **Convert to DFS…** on an ADFS
floppy pane, copies the files into a new image of the layout you choose. Load
and execution addresses, locked access, the disc title and the boot option are
kept. The converted image opens in a new pane, and the source is not changed.
The dialog lists renamed files, and files that will not fit DFS's 31-file,
seven-character, single-level limits, before anything is created. See
*Converting between DFS and ADFS* in the [README](../../README.md).

## Changes

- Greaseweazle reads and writes now always name the Acorn disk layout.
  Previously `gw` chose one from the file suffix and got Acorn media wrong:
  it reads `.adf` as an Amiga disk and `.ssd`/`.dsd` as 40 tracks. A DFS image
  truncated after its last used sector is padded in a temporary copy before
  writing. The original file is not changed.
- Oaknut Disc, ADFS and ROMFS move from 12.18.2 to 13.6.1, a major version.
  Oaknut 13 changes how ROMFS run-only protection is stored, and Acorn File
  Forge now reads and sets it the Oaknut 13 way. The Debian package lock gains
  `oaknut-hfe`, which `oaknut-disc` 13.6.1 requires, and still pins all
  fourteen Oaknut packages to one release.
- The Docker image moves to Python 3.15.
- Gunicorn moves to 27.0.1, Werkzeug in the native package to 3.1.9, and
  Playwright for the browser tests to 1.65.1. Werkzeug 3.1.9 fixes a moderate
  advisory in which `safe_join()` accepted Windows device names. That does not
  affect Linux hosts.

## Repair and format behaviour

- ROMFS files protected as run-only by an earlier release keep that
  protection when listed and when toggled. The protection is stored the way
  Oaknut 13 expects.
- Conversion and drive panes only ever create new images or write a disk on
  request. They do not change any existing repair behaviour.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./acorn-file-forge_1.3.0-1.deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime for HFE and SCP media. Drive panes need
Greaseweazle's `gw` tool installed separately. See the physical floppy guide.

Installing 1.3.0 over 1.2.x preserves native XDG workspace data and Docker
working volumes. Save important open images before upgrading.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
