# Acorn File Forge 1.2.0

Acorn File Forge 1.2.0 adds **Check for Application Updates** to the About
box. A package installed from a release can download and install a newer
release itself. It changes no editing, repair or format behaviour.

## Changes

- Added **Check for Application Updates** to **About Acorn File Forge** in the
  **Help** menu. Nothing is sent until it is pressed. It asks GitHub for the
  latest release, which is never a draft or a prerelease, and reports that
  this is the newest version, that a newer one exists, or why the check could
  not be made.
- A package installed from a release offers **Update to** the newer version.
  It downloads the package built for the same Debian or Ubuntu release and
  architecture to `~/.cache/acorn-file-forge/updates`, checks it against the
  release's `SHA256SUMS`, and installs it with `pkexec apt-get install` after
  the system asks for your password. **Restart Acorn File Forge** then starts
  the new version. Working images, preferences, profiles and the collection
  are kept. A package that does not match its checksum is deleted and nothing
  is installed.
- No update is installed, and the application does not restart, while a
  floppy disk is being read or written through Greaseweazle or a floppy
  controller.
- Only the desktop host installs updates; platform contract version 8 declares
  its install, cancel and restart routes. The Docker service, a source
  checkout and a package built by hand cannot update themselves, and the button
  opens the release page instead.
- Each release package records the system it was built for in
  `/opt/acorn-file-forge/package-target`, and the release workflow checks that
  record against the name the package is published under.
- The release workflow now names each package as GitHub publishes it, with the
  tilde of the revision as a dot, before it takes the checksums. `SHA256SUMS`
  lists the files by the names they are downloaded under, so
  `sha256sum -c SHA256SUMS` verifies the downloaded packages. In earlier
  releases no checksum line matched a downloaded package.

1.2.0 is the first version with the button, so it can update only to releases
published after it. Upgrade from 1.1.3 or earlier by installing the package.

## Repair and format behaviour

No format restriction or repair behaviour changes in this release. Images and
packages written by 1.1.3 and 1.2.0 are interchangeable. The bundled
HxCFloppyEmulator runtime is unchanged.

## Linux packages

The release provides packages for Debian 13 and Ubuntu 24.04 on AMD64, ARM64
and ARMv7. Choose the file matching both the operating system and processor.
For example:

```bash
sudo apt install ./acorn-file-forge_1.2.0-1.deb13_amd64.deb
```

The packages include the native GTK launcher, desktop integration and the
bundled HxCFloppyEmulator runtime for HFE and SCP media.

Installing 1.2.0 over 1.1.3 preserves native XDG workspace data and Docker
working volumes. Save important open images before upgrading.

See the [installation guide](../INSTALLATION.md) and
[Linux desktop guide](../LINUX-DESKTOP.md) for setup and troubleshooting.
